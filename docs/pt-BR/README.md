## Ordem de leitura sugerida

1. **Arquitetura** — entenda o modelo mental de como as peças se conectam.
2. **Configuração** — rode localmente e entenda cada configuração.
3. **Modelo de dados** — aprenda os models Django e os singletons do admin.
4. **Referência da API** — veja todas as rotas e o que cada uma retorna.
5. **Pré-requisitos** — instale Git e Docker antes de implantar.
6. **Implantação** — publique com Docker ou bare-metal.
7. **Contexto do Protocolo KIX** — mapeie a loja sobre as camadas PRISMA.
